# ☕ Grão Nobre - Site de Cafeteria

Bem-vindo ao **Grão Nobre**, um site fictício de cafeteria desenvolvido como projeto acadêmico e de prática em **desenvolvimento web**.  
O objetivo é aplicar conceitos de **HTML**, **CSS** e **JavaScript**, criando um site visualmente agradável, responsivo e interativo.

## 🧠 Objetivo do Projeto

O projeto **Grão Nobre** foi criado com fins educacionais, simulando o site institucional de uma cafeteria moderna.  
Ele foi estruturado em múltiplas páginas com navegação simples e conteúdo interativo para demonstrar:

- Estruturação semântica em **HTML5**
- Estilização avançada com **CSS3**
- Interatividade com **JavaScript**
- Boas práticas de **organização de arquivos**

---

## 🗂️ Estrutura do Projeto
```
📁 Grão-Nobre/
├── cafe.html # Página inicial
├── cardapio.html # Página com o cardápio e função de pedidos
├── contato.html # Página de contato
├── novidades.html # Página de novidades
├── cafe.css # Folha de estilos principal
├── cafe.js # Script para mensagens dinâmicas e destaques
├── cardapio.js # Script de interação com o cardápio
├── imagens/ # Pasta com as imagens do site (café, fundos, etc.)
└── README.md # Este arquivo
```

---

## 💡 Funcionalidades

✅ **Página inicial:**  
- Saudação automática conforme o horário (Bom dia, Boa tarde, Boa noite)  
- Destaques rotativos com JavaScript  

✅ **Cardápio:**  
- Exibição visual do menu  
- Sistema de pedidos interativo com prompts  
- Identificação de itens disponíveis e não disponíveis  

✅ **Contato:**  
- Formulário funcional via e-mail  
- Exibição de endereço e informações de contato  

✅ **Novidades:**  
- Página simples para atualizações e promoções
